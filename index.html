Claude 앱

앱의 Skills 메뉴에서 스킬 전용 ZIP을 추가합니다.

  1. 설정의 Capabilities에서 코드 실행·파일 생성을 켭니다.
  2. Customize → Skills → + → Create skill → Upload a skill을 엽니다.
  3. 아래 ZIP을 올리고 켠 뒤, 새 작업에서 “design-guide 스킬로 진행해줘”라고 요청합니다.

이 방식은 네이티브 스킬 설치와 다릅니다. Skills 메뉴가 있는 환경은 별도 안내를 참고하세요. 이 ZIP의 ChatGPT 업로드는 미검증입니다.

Codex CLI · IDE

작업할 프로젝트 폴더의 터미널에서 실행하세요.

Claude Code

작업할 프로젝트 폴더의 터미널에서 실행하세요.

03

실제로 비교하고, 수정한 모습.

이미지를 누르면 크게 볼 수 있습니다. 제작 자료와 설명을 위한 재현을 구분해 담았습니다.

04

첫 요청은 이 정도면 충분해요.

스킬을 추가했거나 대화용 지침을 붙여 넣었다면, 대괄호를 나의 작업으로 바꿔 요청하세요.

이 디자인 가이드로 [만들 것]을 디자인해줘.
보는 사람은 [대상], 전달할 내용은 [내용].
원하는 느낌은 [방향]이고, 꼭 유지할 것은 [조건]이야.

참고할 디자인과 적용할 부분부터 정리해줘.
같은 내용의 서로 다른 시안을 눈으로 비교할 수 있게 보여줘.
내가 고르기 전에는 하나로 확정하지 마.

이번 제작 절차를 다른 작업에 쓰기 쉽게 정리한 배포판입니다. 같은 디자인 결과를 보장하지 않으며, 시안 선택과 피드백은 사람이 합니다.
